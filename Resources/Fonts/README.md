# Fonts

Atkinson Hyperlegible (Regular and Bold), by the Braille Institute, from Google Fonts.
Licensed under the SIL Open Font License 1.1 (`OFL.txt`), which allows bundling it in the app.
It is the one font for all text in Bip Island; see CLAUDE.md, "Art and voice".

Changed copy: the zero is plain, without the slash (owner decision, 18 October 2026), made by
`scripts/fonts/plain_zero.py`. The licence allows changed copies, and it names no Reserved Font Name, so
they keep the name. Run the script again after replacing these files with a new release.
