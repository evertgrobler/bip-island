# Bip Island — Mini-games & Freshness Plan

Agreed 1 October 2026 (draft — open questions at the end). Live copy: https://claude.ai/code/artifact/b9e0e92e-289f-4afe-a5f7-2b4d4bf8460c

Bip Island gets 28 mini-games across the four islands, built as reusable game types fed by content lists, so every round is different and new games and surprises can be added with each update without touching the rest.

## How freshness works

Novelty comes from five layers stacked on top of each other, so even a child who plays daily keeps meeting something new, while the learning underneath stays steady.

| Layer | What the child notices | How it works | Effort to build |
| --- | --- | --- | --- |
| 1. New rounds every time | Different words, pictures and numbers each round | Each game builds its rounds at random from content lists, at the child's current level | Built once per game |
| 2. New worlds for old games | Bubble Pop becomes balloons at the fair, then fireflies at night | Every game has 3 or more “skins”: same rules, new setting, art and sounds | Art only |
| 3. Bip's daily plan | Each visit starts with a different mix | Bip picks 3 activities per session: one review, one new skill, one favourite, never repeating the last 3 sessions | Built once |
| 4. The island grows | New spots, paths and creatures appear on the map | Mastering a skill reveals a new area on the map, which unlocks its games | Per area |
| 5. Surprises | A mystery box, a golden round, a visitor | Daily and random events layered on top (see Surprises and rewards) | Small, ongoing |

On top of these, every app update can add a whole new game, skin or word list, marked with a “New!” flag on the map so it's the first thing the child sees.

Seven games that move from hearing a sound, to spotting it, to writing it.

| Game | How it plays | Skill | Ages | Skins |
| --- | --- | --- | --- | --- |
| Meet the Sound | The letter bounces in, the narrator says its sound, a picture word follows | First meeting with a sound | 4–6 | Paper desk, chalkboard, sand |
| Sound Hunt | Pick the picture that starts with the sound you hear, out of three | Hearing first sounds | 4–6 | Treasure chests, market stalls, picnic basket |
| Bubble Pop | Letters float up; pop the one that makes the sound | Matching sound to letter | 4–7 | Bubbles, balloons, fireflies |
| Letter Trace | Follow the letter's path with the mouse; sparkles trail behind | Letter formation | 4–6 | Sparkles, snail trail, paint |
| Feed the Monster | Drag only the foods that start with the sound into a hungry monster | Sorting by sound | 4–7 | A new monster every week |
| Letter Fishing | Fish letter-fish out of a pond to match the sound | Speed and recall | 5–8 | Pond, rock pool, river |
| Sound Detective | Find everything starting with the sound in a busy drawn scene | Sounds in context | 5–8 | Beach, kitchen, farm, braai |

## Coding

Seven games that build up from putting things in order to writing small programs for Bip, with no reading needed.

| Game | How it plays | Skill | Ages | Skins |
| --- | --- | --- | --- | --- |
| Pattern Party | Continue the pattern: red, blue, red, blue, … | Spotting patterns | 4–5 | Beads, bunting, footprints |
| Morning Order | Put picture cards in order: wake up, brush teeth, eat breakfast | Sequencing | 4–5 | Routines, recipes, planting a seed |
| Bip's Path | Snap arrow blocks together to walk Bip to his battery | Commands | 4–6 | Island, snow, space |
| Fix-It | Bip's program crashes into a rock: find and swap the wrong block | Debugging | 5–7 | Same maps as Bip's Path |
| Repeat Robot | Do the same walk in fewer blocks with a repeat block | Loops | 6–8 | Same maps, longer paths |
| Puddle Rules | “If puddle, jump”: one program must work on two different maps | If-then conditions | 7–8 | Puddles, sleeping dogs, gates |
| Bip's Dance Party | Program Bip's moves and lights to music, then watch the show | Free creative coding | 5–8 | New songs and stages |

Coding levels are built from small map files, so new puzzles can be added with no new code.

## Surprises and rewards

Surprises reward playing and learning, never paying or waiting: there is nothing to buy, no countdowns and no “come back or lose it”.

| Surprise | When it appears | What the child gets |
| --- | --- | --- |
| Bip's mystery box | First visit of each day | A sticker, a new part for Bip, or a decoration for the island |
| Golden round | About 1 round in 15, at random | Letters or numbers turn gold; finishing earns a double sticker |
| Island visitors | After every few sessions | A new creature (a penguin, a tortoise, a hadeda) moves onto the map and asks for help with a game |
| New areas | When a skill is mastered | A new beach, cave or treehouse appears on the map with its games inside |
| Bip's workshop | Anytime | Kids dress Bip with earned parts: hats, paint, antennas, wheels |
| Island decorating | Anytime | Earned items (palm trees, flags, a lighthouse) can be placed on the map |
| Special days | Birthday, holidays, Heritage Day | Bip has a party hat, and a themed skin runs for the day |
| “New!” flag | After an app update | Whatever the update added glows on the map until it's tried |

The sticker book shows every sticker as a grey outline until earned, so kids can see there's always more to find.

## Making it robust

The game is split into three separate parts, so adding a new game or new words never risks breaking the ones already on your child's Mac.

1. **Content lists** (plain data files): every word with its sounds, picture and voice clip; every number set; every coding map. Adding 50 new words is a data change, not a code change.
2. **Game types**: each mini-game follows the same template. It says which skills and ages it teaches, builds a round from the content lists at the child's level, checks the answer, and lists its skins. A new game is one new file that plugs in.
3. **Bip's planner**: picks what to play next from the child's progress, what's due for review, and what they haven't seen lately. It works the same for 10 games or 100.

Automatic checks run on every update before it can reach your Mac:

- **Every round is fair:** the build plays 1,000 random rounds of every game and fails if any round has no right answer, two right answers, or a distractor that sounds the same.
- **Nothing is missing:** every word must have its voice clip and picture, or the build stops.
- **No repeats:** the same word never appears twice in one session.
- **Progress is safe:** a new version always reads your child's saved progress from the old one, and the check fails if it can't.
- **One bad game can't sink the app:** if a game fails to load, Bip quietly skips it and the rest keep working.

## Build order

The plug-in template and Bip's planner come first, so every later game is quick to add.

| Phase | Games added | Freshness added |
| --- | --- | --- |
| 1. Prototype (being built now) | Meet the Sound, Sound Hunt, Bubble Pop | Random rounds |
| 2a. Core of each island | Letter Trace, Feed the Monster, Count & Tap, Quick Look, Sound Buttons, Word Builder, Morning Order, Bip's Path | Bip's daily plan, sticker book, mystery box |
| 2b. Second wave | Number Train, More or Less, Missing Letter, Rhyme Time, Pattern Party, Fix-It | Skins (3 per game), golden rounds |
| 3. Polish | Letter Fishing, Sound Detective, Ten-Frame Garden, Tricky Word Memory, Silly Sentences, Repeat Robot, Bip's Dance Party | Island grows, visitors, Bip's workshop, decorating |
| 4. Older kids | Spaza Shop, Word Rocket, Puddle Rules | Special days |
| Ongoing | A new game, skin or word list with each update | “New!” flag on the map |
